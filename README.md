# CSCE 3530 - Virtual College Study Lounge Network

**Student:** Hema Thallapareddy  
**Course:** CSCE 3530 - Computer Networks  
**Instructor:** Dr. Ali Zarafshani  

## Project Overview
A virtual college study lounge network built in Cisco Packet Tracer 
demonstrating HTTP, DNS, TCP, UDP, ICMP, and ARP protocols.

## Network Design
- 3 Student PC clients (192.168.1.10-12)
- 1 Cisco 2911 Router (192.168.1.1)
- 1 Cisco 2960 Switch
- 1 Combined DNS/HTTP Server (192.168.1.20)
